# LOOK Astana

Сайт салона красоты: услуги, цены и заявка в WhatsApp.

## Публикация на GitHub Pages

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Сайт работает без сборки и серверной базы данных. Выбранные день и время являются пожеланиями клиента; запись подтверждает администратор в WhatsApp.

## Изменение прайса

Услуги и цены находятся в app.js. Фотографии, иконки и шрифты находятся в assets/.
